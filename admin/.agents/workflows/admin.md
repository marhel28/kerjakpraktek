Frontend rules untuk PasarCctv menggunakan Nuxt 4, Vue 3 Composition API, Tailwind CSS, dan Nitro API. Fokus pada UI marketplace modern ala Tokopedia dengan tampilan natural, clean, mobile-first, dan tidak terasa AI generated. Semua komponen wajib responsive, SSR safe, hydration safe, serta production-ready. Gunakan Tailwind utility native, reusable component, clean spacing, rounded modern card, soft shadow, dan performa optimal. Hindari design futuristik berlebihan, gradient norak, glassmorphism berat, overflow horizontal, dan code tidak maintainable. Output harus full final code, scalable, responsive Android friendly, serta menjaga konsistensi brand PasarCctv.
