ENDPOINT SUMMARY
================

PUBLIC:
  GET  /promos                     — list promo aktif
  GET  /promos/flash-sale          — list flash sale
  GET  /promos/{slug}              — detail promo
  POST /promos/validate            — preview harga (no commit)
  POST /promos/checkout            — checkout + Midtrans
  POST /promos/webhook/midtrans    — Midtrans callback
  GET  /promos/my-orders           — riwayat order promo user
  GET  /promos/order/{order_id}    — detail order promo

ADMIN:
  POST   /admin/promos             — buat promo (status DRAFT)
  GET    /admin/promos             — list semua promo
  GET    /admin/promos/{uuid}      — detail promo
  PATCH  /admin/promos/{uuid}      — update metadata
  POST   /admin/promos/{uuid}/publish   — publish
  POST   /admin/promos/{uuid}/pause     — pause
  DELETE /admin/promos/{uuid}      — soft delete/arsip
  POST   /admin/promos/{uuid}/items     — tambah item
  DELETE /admin/promos/{uuid}/items/{item_uuid}  — hapus item
  GET    /admin/promos/stats       — statistik


PROMO TYPE & BEHAVIOR
=====================
PERCENTAGE  : disc_value% dari harga, dibatasi max_discount
FIXED       : potongan flat Rp disc_value per item
BOGO        : beli buy_quantity gratis get_quantity (hitung per item)
BUNDLE_DISC : disc_value% dari total bundle (cocok untuk paket jasa)
FLASH_SALE  : seperti PERCENTAGE + flash_sale_quota terpisah

PROMO TARGET:
  STOCK           : hanya berlaku untuk produk (Stock)
  SERVICE_PACKAGE : hanya untuk paket jasa
  ALL             : berlaku untuk semua item

Jika ada PromoItem spesifik → hanya item terdaftar yang dapat diskon.
Jika tidak ada PromoItem → semua item sesuai target mendapat diskon.
